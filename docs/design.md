# 管理界面设计：三套皮肤

状态：v2 定稿（2026-10-22）。设计稿在 `design/`，实现以本文与设计稿为准。

规范图：01–02 为侧栏底部弹层（2026-10-21 版）；03–10 为页面规范（仪表盘 / 任务 / 会话 / 整理 / 接入 / 隐私 / 已删除 / 配置），文件在 `design/components/memrelay-*-spec.png`。页面规范源文件在 `design/components/src`，预览使用演示数据，尺寸与色值取自当前实现实测。

## 概念

界面是本地会话的「调度台」：左侧固定导航，右侧按页面展示仪表盘、任务、会话、整理、接入、隐私、回收站与配置。视觉上提供三套可切换皮肤，结构和信息架构完全一致，只换渲染语言：

| 风格 | 关键词 | 典型元素 |
|---|---|---|
| 简洁 minimal | 留白、1px 细线、单一朱红强调 | 18px 圆角卡片、柔和投影、系统无衬线字体 |
| 漫画 comic | 暖色奶油纸、粗墨线、手绘感 | 双线卡片框、硬偏移投影、朱红刷痕、幼圆/楷体 |
| 像素 pixel | 中性暖色平面像素 | 直角、2px 描边、四方向硬投影、像素字与切角外框 |

共同底线：中性暖色，不使用粉色/桃色/珊瑚色；不出现日文、印章、地图、风景、插画或带脸角色；不使用噪点、扫描线、CRT 效果。

## 布局

- 侧栏 300px：品牌区（机器人 mark + MemRelay 字标 + 右上角版本号）、主导航（仪表盘 / 任务 / 会话 / 整理 / 接入）、分隔线、次级导航（隐私 / 已删除 / 配置）、底部菜单（主题 / 语言 / 快速导览）。
- 正文内边距 38px 56px，内容最大宽度 1300px；主文本 14px，次要元信息 11–12.5px。
- 卡片：简洁 18px 圆角 + 1px 描边 + 柔和投影；漫画不规则圆角 + 2px 墨线 + 硬投影；像素直角 + 2px 描边 + 硬投影。
- 页面底部动作栏（接入 / 配置）跟随内容流；配置页保存栏吸底。
- 窄屏：≤1280px 收紧留白；≤1080px 侧栏 264px、双列页面转单列；≤820px 侧栏转横向顶栏，底部菜单隐藏，主题 / 语言 / 快速导览入口移到配置页顶部。

## 侧栏菜单

- 品牌行右侧放构建版本号，不占用菜单层级。
- 菜单顶部 1px 分隔线；底部入口为「主题 / 语言 / 快速导览」。
- 快速导览只在点击底部入口时启动，不自动弹出：依次走向接入 → 仪表盘 → 任务 → 会话 → 整理，自动切页并把侧栏对应入口聚光；卡片说明这一步的价值，支持上一步 / 跳过 / 完成、←/→ 与 Esc，结束或跳过回到进入前的页面。聚光只落在稳定的侧栏入口，不追页面内每个按钮；窄屏入口在配置页顶部。
- 主题弹层：宽度 286px，三组三分段——风格（简洁 / 漫画 / 像素）、模式（浅色 / 深色 / 跟随系统）与动效（开启 / 关闭 / 跟随系统）；选中项实心反色。
- 语言弹层：按实际支持范围列出 11 种语言（简体中文 / English / 繁體中文 / 日本語 / 한국어 / Español / Français / Deutsch / فارسی / Português (BR) / Bahasa Indonesia），左侧原生名、右侧译名，选中项反色胶囊；列表超高可滚动。
- 选择立即生效并写入 localStorage（`memrelay-style` / `memrelay-mode` / `memrelay-motion` / `memrelay-lang`）；默认简洁 / 浅色 / 动效开启，没有保存值时才使用这些默认，语言仍跟随浏览器。点击外部或 Esc 关闭。

## 页面结构

1. **仪表盘**（默认首页）：标题/副标题（任务数、目录数、最近写入）与刷新；概览卡（进行中 / 中断 / 完成 / 放弃 / 未判定 / 已删除，零值也显示；全部卡片可点击，状态卡进入任务页对应筛选，已删除卡进入回收站；卡片只保留图标、名称与数值）；全宽近 14 天活动柱（悬浮显示当天会话数）；下方 2×2 卡片——「待接力」中断任务与「最近任务」（标题垂直居中、标题与查看全部两端对齐），工具分布（按会话计）与活跃目录，同一行的卡片等高、底部对齐；中断为空时「待接力」显示全清空态。页面每 30 秒静默刷新。任务行为跨项目列表，工具链以「Qoder → Claude Code」呈现。
2. **任务**：标题/副标题、任务搜索、重新索引、状态筛选 pill + 最近活动排序、按目录分组的卡片（组头路径与计数、任务行、组底「查看全部 N 个任务」）。任务行含标题、摘要、来源工具、状态、时间、消息/文件数。搜索与状态筛选走服务端；状态筛选写入 URL（`?status=…`），支持从仪表盘直接深链；列表每 30 秒静默刷新。
3. **会话**：搜索 hero（Ctrl/Cmd+K 聚焦）、来源筛选、按今天/昨天/更早分组的会话卡、来源头像、状态与时间。
4. **整理**：顶部立即整理/撤销下发；来源列表；「已下发的统一偏好」与「待拍板（未写入下发块）」分成两张卡；右侧运行状态与已下发文件；左右两栏底部对齐（右栏最后一张卡补足高度，说明贴底）。
5. **接入**：2 列工具卡（图标、名称、路径、说明、接入状态、能力标签、选择框），底部动作栏显示待应用变更、自测与应用。未安装工具呈虚线禁用态。
6. **隐私**：三张概览卡（排除目录、疑似密钥、自动脱敏）+ 左右两栏（排除目录与空态/添加框；按规则分组的密钥列表与脱敏预览）。密钥组可展开查看会话定位。
7. **已删除**：搜索、全部恢复、提示条与排序标签、按目录分组的恢复列表。只移除 MemRelay 索引，不碰原工具文件；回收站保留期与清空能力在后端落地前不展示。
8. **配置**：左栏会话摘要、偏好整理、语义检索、自动接入；右栏运行状态、摘要队列与本地数据说明；底部吸底保存栏。语言与主题不在配置页重复。

## 色彩

每套皮肤各含浅色/深色令牌，全部通过 CSS 变量切换（`data-style` + `data-theme`）。核心语义：

- `bg / surface / surface-2 / surface-3`：页面、卡片、次级底、更深的填充
- `border / border-strong`：结构线
- `text / text-2 / text-3`：主、次、弱文字
- `accent`：唯一品牌强调色（朱红），用于主按钮、选中态、链接与刷痕
- `green`：进行中、成功、实时索引
- `amber`：中断、扫描索引、旧摘要等警示
- `blue`：仅用于来源与能力标签
- 像素皮肤的侧栏在浅色下仍是深棕（深色侧栏 + 奶油主面板），其余皮肤侧栏与页面同底。

## 字体

| 皮肤 | 正文 | 标题 | 等宽/数据 |
|---|---|---|---|
| 简洁 | Segoe UI / Microsoft YaHei UI | 同正文，750 字重 | Cascadia Mono / Consolas / IBM Plex Mono |
| 漫画 | 幼圆 YouYuan | 楷体 STKaiti/KaiTi | Segoe Print / Comic Sans MS |
| 像素 | SimSun | SimSun 800 | Departure Mono / SimSun |

所有文字（含页副标题、弹层分组标题、来源头像字母、工具图标字母）都落在这三列字体里，不回落系统无衬线；新增文字元素时按皮肤补字体规则。

数字使用 tabular-nums；字体优先本地，不依赖网络。

漫画标题用幼圆，而幼圆只有 400 字重。不要用 600/700：Chrome 的合成加粗会把「与 / 时」这类稀疏笔画画成空心灰字；用 400 + `-webkit-text-stroke: 0.03em` 模拟加粗。

像素标题用宋体，宋体没有粗体字面，Chrome 也不会做合成加粗；页标题用 `-webkit-text-stroke: 0.05em`、条目/面板标题与统计数字用 `0.03em` 补回重量。

## 状态与标签

- 状态胶囊：进行中（绿）、中断（琥珀）、完成（灰）、放弃（灰 + 删除线标题）、未判定（灰）。
- 能力标签：启动提示（蓝）、实时索引（绿）、扫描索引（琥珀）、只读/需信任/插件（灰）。
- 漫画与像素皮肤把胶囊和标签改为描边样式，不填充大色块。
- 状态不单靠颜色，始终带文字。

## 交互与动效

- 页面切换约 160ms 淡入；中断状态的接力灯保留呼吸动效。
- 快速导览的聚光与卡片随站点移动，光轨火花在每次换站时跑一次；三套皮肤各用自己的时长与缓动，动效关闭或系统要求减少动态时直接切换。
- 复制续接提示词后按钮短暂显示「已复制」。
- 所有危险操作使用两步确认。
- 尊重 `prefers-reduced-motion`。

## 文案

- 简体中文为主，其余 10 种语言完整镜像；首次使用按浏览器语言匹配（简/繁中文、日、韩、西、法、德、波斯、葡（巴西）、印尼），匹配不到用英文；之后优先沿用 localStorage 里的选择，可在侧栏切换。波斯语按 RTL 渲染，方向性样式统一用逻辑属性。
- 动词说清结果；空状态给出下一步；错误说明发生了什么、怎么解决。
- 状态词与架构文档一致：进行中 / 中断 / 完成 / 放弃 / 未判定。

## 可访问性底线

键盘全程可达；focus ring 使用 `accent` 2px、偏移 2px；文字对比度按 AA；弹层可用 Esc 关闭；状态同时有文字标签。
